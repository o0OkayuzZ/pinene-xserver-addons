# Codexへの投入指示

このフォルダの `00_README_FOR_CODEX.md` から順番に読み、キノコ鑑定士システムを `o0OkayuzZ/pinene-xserver-addons` の既存統合BP/RPへ統合してください。
**資料整理だけで終了せず、実物のモデル・UV・35アイテム・鑑定・図鑑・効果・NPCをコードへ統合する作業です。**

## 絶対条件

既存のmanifest、UUID、依存関係、ロード順、既存Scriptを無断で置換しない。`pack/BP/scripts/main.js` はテスト用なので、既存main.jsをこれで上書きしない。`import "./mycology/index.js";` を重複なく追加する。

実装候補には実機未確認部分がある。最初に現在のブランチとBedrock実行バージョン・`@minecraft/server` / `server-ui` の互換性を調べ、必要なAPI/JSONの修正を行う。実機試験をしていなければ「ゲーム内テスト済み」と書かない。

承認仕様：赤15種、茶20種。バニラ赤/茶の**最初の該当スロット1つ全量（1–64個）**を、1個ごとに独立抽選して種類別に集約。ウェイトは `2^(10-rarity)`。進捗はプレイヤー別。図鑑は未発見の名前・レア度・本文を隠す。

NPCは通知・台詞・派手な演出なし。通常4%／キノコ島20%、15分ごとの世界共通抽選、有効自然個体1体、30分／45分滞在、UI中のみ最大5分猶予。自然個体が死亡した場合だけ赤64＋茶64。管理用summonと期限消滅からは出さない。

NPCモデルは承認デザインを軽量化した**45 cubes / 12 bones、128×128の実UV**。35アイコンは32×32 RGBA。高解像度参照画像は直接ゲームへ入れず、`reference/final_32x32/` と runtime の32×32 PNGを使用する。参照画像をそのままアトラスとして使わない。画像の旧ID・誤表記でregistryを上書きしない。

毎tickの全プレイヤー・全Mob・全所持品走査は禁止。必要な低頻度スポーン時計、保留中だけの遅延毒、3回限りの探知処理は許可。既存別システムの毎tick処理を本作業のために全面改修しない。

科学説明とゲーム表現、ジョークを分離する。根拠不足を新しい化合物名で補わない。研究・ポーション・調理・買取・戦闘NPC化は追加しない。

## 作業と報告

`npm test`、`python tools/validate.py`を実行。公式2.7型定義で静的照合を追加し、`docs/ACCEPTANCE_TESTS.md` のゲーム内試験を実施する。特に死亡イベント内のentity参照、共有クールダウン、UIの連打、再起動/チャンクアンロード、余剰ドロップ、インベントリ障害復旧を優先する。

既存UUIDのバージョンを必要な分だけ一貫して更新し、root/worldのpack参照・依存側も確認する。元のworldデータを変更せず、テスト用ブランチ/コピーで進める。本番デプロイや強制pushはしない。

完了時は変更ファイル、実施した試験、未実施試験、既知の制限、配布サイズ、残課題を報告する。モデル差分を追加した場合はプレビューを再生成する。
