# 制作物と参照素材

実装用PNG、geometry、アニメーション、アイコンは本作業で作成した。承認済みデザインの色・衣装・小物を参照し、低解像度に再設計している。元の高精細イラストを1:1でUV化したものではない。

NPCは128×128 RGBAアトラス1枚、45 cuboids / 12 bones。曲面・ハイポリ・追加装飾エンティティなし。ルーペのレンズと標本瓶は軽量な不透明ピクセル表現で、屈折シェーダーを用いない。

35アイコンは32×32 RGBA。図鑑？アイコン16×16、機能粒子16×16、パックアイコン64×64。アルファは0/255を基本とし、生成画像にあった微細な縁の半透明ノイズをそのまま持ち込まない。

`previews/NPC_actual_model.png` は**付属geometryとUVから描画したソフトウェアレンダリング**。Minecraftのスクリーンショットではない。静止姿勢だけで、アニメーションの実機品質は別試験。

`reference/` のWebPは会話内で承認されたNPCデザインの縮小版。ラベルや細部はあくまで参照で、`data/mushrooms.json`や実装geometryを上書きする根拠にはしない。

新規制作物はこのプロジェクトで編集・統合する前提の素材です。第三者の既存スキンやMojangのテクスチャファイルを転載していません。ただしMinecraftの名称等について公式提携を意味しません。参照する論文・公的資料の権利は各権利者にあり、本文の全文コピーを同梱していません。

システムに入っているフォントはプレビュー生成時だけ使用。フォントファイルそのものを再配布していません。


## v1.1.0 texture pass

2026-09-10にキノコの自然な非対称性を重視した見直しを実施。v1.2では全35種を32×32へ統一し、B05 / B15–B20 / R13 / R14 は高解像度の個別確認版から32×32へ再サンプリングした。その他は承認済み16×16シルエットを最近傍2倍して互換性を保ち、Codex実機確認後に差し替え可能な構造にした。高解像度の採用元は `reference/texture_sources_approved/`、ゲームへ入る正規32×32は `reference/final_32x32/`。

`tools/build_assets.py` は編集可能なプロシージャル素材を作った後、**必ず `reference/final_32x32/` の35枚を復元する**。したがって承認済みアイコンを変更する場合は実行用PNGだけでなく、このcanonicalフォルダも更新すること。
