# Codex — キノコ画像差し替え v1.4.0

既存の Pinene Mycology システムへ、添付の v1.4.0画像セットを反映してください。
システム実装は既存v1.3等を継続し、画像についてのみ本セットを優先してください。

1. `asset_manifest.json`でR01〜R15 / B01〜B20の35種、item ID、texture key、パス、SHA-256を照合する。
2. 完全画像ZIPなら`codex_overlay/`の内容を既存Codexパックのルートへ重ねる。小型Texture_Update ZIPでは`pack/`と`reference/`が直下にあるので、それらを重ねる。
3. `pack/RP/textures/items/mycology/*.png`と`reference/final_32x32/*.png`へ同一画像35枚を反映する。片方だけ更新しない。
4. 既存ビルダーが読む画像の正を`reference/final_32x32/`に統一し、古い16×16ソースや古い承認画像から上書きしない。再ビルド前後の画像SHA-256を比較する。
5. 既存サーバー統合RPへ導入するときは実際のRPルートを確認し、対応する`textures/items/mycology/`へ反映する。ID・texture key・相対パスは変更しない。
6. この更新を理由にregistry、能力、レア度、図鑑本文、NPC、manifest、UUID、main.js、ロード順を変更しない。高解像度原画や一覧をRPへ入れない。
7. 実行環境が使える場合はインベントリ・手持ち・ドロップ・図鑑での描画を確認する。実機環境がない場合は「未確認」と報告し、確認済みとしない。
8. 変更ファイルと検証結果を報告する。本番配備は指示があるまで行わない。

元画像は個別に生成された1254×1254 PNG、実装版はそこから変換した32×32です。
元画像35枚を保持している完全画像ZIPでは、`tools/rebuild_32x32.py`で再変換できます。
R13は誤った後発の棒状画像ではなく、確認済みの星状・腕状の画像です。
B16〜B20は最後にユーザーが確認した5枚の元画像を維持しています。
