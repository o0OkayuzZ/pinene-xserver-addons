# Texture Pass v1.2 — 32×32 handoff

更新日：2026-09-10。Minecraft Bedrock向け32×32 RGBA、バイナリアルファ。

## 方針

- 全35種のゲーム内アイコンを32×32へ統一。
- バニラ寄りの粗いピクセル感、左右非対称、傾き、群生の密度差を優先。
- 木片・背景など、キノコの識別に不要な要素はランタイムアイコンへ持ち込まない。
- 高解像度生成画像は参照素材。ゲーム内Source of Truthは `reference/final_32x32/`。
- B05 / B15–B20 / R13 / R14 は会話内の個別確認版から32×32化。
- その他26種は承認済み16×16のシルエットを最近傍で32×32へ拡大した互換候補。実機で見て必要な種だけ後から32×32描き直し可能。

## 注意

32×32化は視認性を上げるが、ファイルサイズとランタイム負荷は同義ではない。ゲーム内インベントリ、ドロップ表示、図鑑フォームの見え方を実機で確認すること。
