計測の接続設定

キーはこのPCで暗号化保存

最初の接続だけ設定が必要です。キーをチャットや公開リポジトリに貼り付けず、以下に入力してください。

  1. Google Analyticsを開く → PINE SERVERのプロパティとWebデータストリームを作成。URLは https://o0okayuzz.github.io/pine-server/ にします。
  2. 「G-」で始まる測定IDと、数字のプロパティIDを下に入力します。測定IDだけは公開用です。拡張計測はスクロール・離脱クリック・動画・ダウンロードをONにします。サイト内検索・フォームの操作・ページビュー詳細の「ブラウザの履歴イベントに基づくページの変更」はOFFにしてください。
  3. Google Analytics Data APIを有効化し、読み取り用サービスアカウントを用意。そのメールアドレスをGA4のプロパティの「閲覧者」に追加します。
  4. サービスアカウントのJSONキーを下に貼り付けて保存します。キーはこのWindowsユーザーでのみ復号できる形式で保存します。

保存後の実データ取得には、APIの有効化・閲覧権限・計測コードの公開が必要です。サイト側は訪問者が計測を許可したときに開始する構成です。

Cloudflare Web Analyticsにサイトを登録してください。公開サイトへの計測コード設置は完了しています。次は以下の読み取り設定を行ってください。

  1. Cloudflareの登録サイトを開き、アカウントID・サイトIDを下に入力します。公開用トークンとは別のIDです。
  2. APIトークンを作成でカスタムトークンを作り、権限を「Account / Account Analytics / Read」、対象をこのサイトのアカウントだけにします。
  3. 発行したトークンを下の「読み取りAPIトークン」に貼り付け、「接続設定をこのPCに保存」を押します。チャットへ貼り付ける必要はありません。
  4. 「最新の状態に更新」で実データを確認後、「GitHubへ保存」で本人用レポートを更新します。

計測用トークンだけでは数値を取得できません。

計測内容・読み方・できないこと
  • ページ表示、コンテンツ別閲覧、図鑑検索の使用、絞り込み、一覧展開、レシピ移動、参加案内へのクリックを集計します。
  • 検索に入力した文章・氏名・メール・IPアドレス・個人の閲覧履歴一覧を、この管理画面の保存対象にはしません。
  • クリック件数を並べただけでは、同じ人の移動順や離脱率は分かりません。詳しい経路・ファネルはGA4の探索画面で条件を設定して確認します。
  • 計測前の訪問、同意しなかった訪問、ブロッカーで止まった計測は取得できません。表示まで時間がかかる場合があります。
  • CSVとJSONの保存先はブラウザで選びます。GitHubへの保存は非公開リポジトリの確認後に行います。
