# BlueAppleResetV1

このパックは、青りんご系アイテムだけを切り出して安定動作するように作り直した、最小構成のテスト兼本体パックです。

いま入っているアイテムは次の3つです。

- 青りんご
- ダイヤ青りんご
- エンチャント青ダイヤりんご

## 入手方法

このパックの入手方法は、前と同じで次の3通りです。

### 1. オーク系の葉を壊して青りんごを拾う

オークの葉 / ダークオークの葉を壊したとき、低確率（0.5%）で青りんごがドロップします。

### 2. クラフトで作る

- ダイヤ青りんご:
  - レシピ: ダイヤ8個で青りんご1個を囲む
- エンチャント青ダイヤりんご:
  - レシピ: ダイヤブロック8個でダイヤ青りんご1個を囲む

### 3. クリエイティブインベントリから取る

アイテム一覧の中に追加されます。

### 4. コマンドで入手する

```mcfunction
/give @s resetapple:blue_apple 1
/give @s resetapple:blue_diamond_apple 1
/give @s resetapple:enchanted_blue_diamond_apple 1
```

## アイテム説明

### 1. 青りんご

- ID: `resetapple:blue_apple`
- 見た目: 青いりんご
- 食べられる: はい
- 栄養: 20
- 満腹でなくても食べられる: はい
- 特徴: シンプルな基本版の青りんごです

### 2. ダイヤ青りんご

- ID: `resetapple:blue_diamond_apple`
- 見た目: 青りんごを強化したダイヤ版
- 食べられる: はい
- 栄養: 18
- 満腹でなくても食べられる: はい
- 食べたときの効果:
  - 再生 I: 約30秒
  - 水中呼吸: 約12分
  - 暗視: 約12分
  - 移動速度 I: 約6分

### 3. エンチャント青ダイヤりんご

- ID: `resetapple:enchanted_blue_diamond_apple`
- 見た目: エンチャント版の青ダイヤりんご
- 食べられる: はい
- 栄養: 120
- 満腹でなくても食べられる: はい
- グリント: あり
- 見た目補足: 紫のグリント感が目立つように、エンチャント用アイコンを強調版にしています
- 食べたときの効果:
  - 再生 II: 約90秒
  - 吸収 III: 約30分
  - 耐性 I: 約20分
  - コンジットパワー: 約30分
  - 水中呼吸: 約30分
  - 暗視: 約30分
  - 移動速度 I: 約20分

## この段階での仕様

- まずは安定して表示、入手、使用できることを優先した構成です
- ワールドでは world-local の最小 pack として動かしています
- `saturation_modifier` は、この環境で安定した数値形式を使っています
- 他アドオンと混ぜる前に、この3アイテムだけで動作確認する前提です

## トラブル時の確認ポイント

もしアイコンが出ない、名前が変、古いエラーが残る場合は、次を確認してください。

1. ワールドがこの pack だけを読んでいるか
2. Minecraft を完全終了してから再起動したか
3. キャッシュ整理スクリプト `tools/maintenance/reset_bedrock_pack_cache.ps1` を実行したか
4. `/give` で `resetapple:*` の ID を使っているか
