# ピネ各種素材パック (Behavior Pack)

このパックは、他のアドオンで再利用する共通素材アイテムを一元管理します。

## 目的
- 素材アイテムIDをこのパックに集約
- 他アドオンはこの素材IDを参照するだけにする
- 素材仕様変更を1か所で管理

## 推奨運用
1. 新素材は `items/` に追加
2. 必要なら `recipes/` に基本加工レシピを追加
3. 互換性に影響する変更は `version` を更新
4. 参照先アドオンの依存バージョンを同期

## フォルダ構成
- `items/`: 共通素材アイテム定義
- `recipes/`: 素材の基本レシピ
- `loot_tables/`: 素材ドロップ
- `scripts/`: 必要時のみ利用
