# ピネ鯖 金食料系列 / Codex引き継ぎセット

## 使い方

このフォルダまたはZIPをCodexの作業環境に置き、`CODEX_PROMPT.txt` を依頼文として渡してください。仕様の正本は `Pinene_Golden_Foods_Spec_v0.1.1.md` です。

v0.1.1では、重ね食い許可、完成料理としての金パイ強化、既存エンチャント金リンゴのクラフト維持、きらめくスイカ可食化の優先、エンチャント金小麦3個からのパン代替レシピ復活、食事時の科学通知撤廃を反映しました。

| ファイル | 用途 |
|---|---|
| Pinene_Golden_Foods_Spec_v0.1.1.md | 全系列・最新変更・レシピ・性能・科学UI・実装条件・試験の統合仕様 |
| balance_seed.json | 試験用数値とID・画像共有・レシピ・科学文章の設計データ |
| CODEX_PROMPT.txt | Codexへ貼る実装依頼文 |
| SPEC_VALIDATION.json | 同梱データの整合性検査結果。ゲーム内テストではない |
| README.md | この案内 |

これは仕様の引き継ぎセットです。mcaddon、mcpack、完成PNG、実装済みスクリプトは含みません。Gitの変更、push、サーバー配布、ゲーム内試験は行っていません。

仕様では「確定ルール」「会話の候補値」「今回の仮置き」「能力検証が必要」「保留」を分離しています。全てを検証済み・最終バランス済みと解釈しないでください。
