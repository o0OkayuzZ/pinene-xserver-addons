# BSL v3 最終適用仕様

2026-09-24。ユーザーの「BSLを決めて早く適用」に基づく。PR #20の`e26a7622`を元に、BSLだけを完成させる。GF・鑑定士・自動修復の未統合PRを混ぜない。

## 通常33テーブル

Early 15–19、Mid 16–20、High 17–22、End 18–23を、**レア枠込みの全体抽選回数**として確定する。v2のベース抽選に追加する方式ではない。
独立して抽選するレア枠を先に予算内へ確保し、外れた枠では同じ宝箱の通常報酬を引く。レアの当選確率とレアの個数・メタデータは厳密に保持する。追加枠による27枠超過を廃止し、当選時に固有報酬があふれる構成を作らない。
通常報酬の品目・相対重み・個数・機能、およびPR #20の構造物固有の追加品は維持。安価なバニラフィラーは復元しない。

## 特殊3テーブル

すべて各分岐で27個の非空ItemStackを生成する。物理的な表示・マージは別途ネイティブで検証する。
- アイスボックス: エンチャント金食料16枠×3–6個（48–96個）、金食料3枠×4–8個、エンチャント金リンゴ確定1枠×2–4個、パンケーキ2枠×2–4個、資源／レア置換3枠、氷塊・雪玉各1枠×8–16個。食べられない小麦は食料枠から除外。
- 砦の宝物: 確定の鍛冶型＋8資源等アンカー、進行レア置換1枠、資源4枠、装備6枠、レア置換7枠＝27。ネザライト強化用鍛冶型を単独確定プールへ分離する。誤って競合していたダイヤ槍は装備プールへ重み6で移す。進行レアはDeathnerite ingot 18%、既存darkness型紙10%、それ以外は資源。
- 埋もれた宝: 海洋の心＋9資源等アンカー、海洋資源4枠、装備4枠、レア置換9枠＝27。海洋の心は単独確定。各アンカーの豪華な数量、トライデント18%等のレア確率を保持。

共有食料・収集品テーブル、無限城の宝箱は変更しない。通常Trialからメイス／ヘビーコアを、通常End Cityからドラゴンの卵を出さない。Dungeons専用品を一般BSLに追加しない。

## 実装・検証

正本generatorは`tools/build_bsl_release_v3.py`。`--write`で再生成し、引数なしで一致検査。元データの既承認commitを固定して二重縮小を防ぐ。
validatorは`tools/validate_bsl_release_v3.py`。旧`validate_bsl_weighted_rebalance.py`コマンドも新validatorへ渡す。古いv2ビルダーの定数だけを読んで合格にはしない。
BP01は1.0.23。UUID、依存API、読み込み順を維持する。稼働済み・開封済みの宝箱の中身を再配布しない。定期走査、補充Script、テレポートフックを追加しない。
ネザー移動後のラージチェストの表示／取り出し異常は別件であり、この報酬修正で直ったとは扱わない。

## 今回の適用判断（2026-09-24）

ユーザーが実機受入試験を省略して先行適用することを明示的に承認した。これを実機合格とは記録しない。
隔離BDSでの試行は、認証設定・loot用IDの事前列挙・テスト用チャンクの未ロードで抽選実行前に停止しており、チェスト実抽選の成功件数は0。これ以上の実機試験は今回の配備条件にしない。
静的検証はBSL回帰22件、generator一致、通常33＋特殊3テーブルの再帰的スタック数境界、238レア枠の確率照合、アイスボックス1万回シミュレーション、メタデータ5件、ownership監査、差分検査が成功。
生成ItemStack数の証明と、Bedrockでの表示・格納・スタック分割を混同しない。既存の一部loot用IDのScript API上の別名も、今回の実機未確認事項として残る。
配備はBP01とその登録versionだけを対象とし、サーバー停止中のバックアップ、変更対象の事前ハッシュ、起動・ログ確認を行う。開封済みチェストの中身・ワールドDBを編集しない。
GF／鑑定士のPR #21、`pineHasTag`未定義など既存の別件は、このBSLリリースに混ぜない。
