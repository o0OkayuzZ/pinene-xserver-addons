Important Deathnerite note
The repository does not contain an active item definition for true_dn:deathnerite_upgrade_smithing_template.
Deathnerite equipment is crafted from true_dn:deathnerite_ingot, while Parcanite uses
true_dn:darkness_upgrade_smithing_template. Therefore the agreed Deathnerite progression
slot is implemented with true_dn:deathnerite_ingot rather than a nonexistent template item.
