# 金の卵・金のコーラス追加

既存の金食料の能力、通常リンゴシチューの図鑑除外、金の羽／Waystoneの定義は維持し、2系列4アイテムを追加。
既存ファイルの変更はスクリプト登録、図鑑への4項目追加、アイコンの参照、パックのバージョンと登録情報に限定。

## アイテムと実際の設定

| 日本語表示 | identifier | 能力 |
|---|---|---|
| 金の卵 | `a:gegg` | プレイヤー直撃：再生II 8秒、攻撃力上昇I 60秒、小量の満腹度・隠し満腹度補給 |
| エンチャントされた金の卵 | `a:egegg` | プレイヤー直撃：再生II 20秒、攻撃力上昇II 90秒、大量の満腹度・隠し満腹度補給、追尾補助 |
| 金のコーラスフルーツ | `a:gchorus_fruit` | 視線方向へ最大24ブロック |
| エンチャントされた金のコーラスフルーツ | `a:egchorus_fruit` | 通常最大64ブロック、エンド96ブロック。スニーク時だけ高度ワープUI |

- 金版レシピ：通常の卵／コーラスを中央に、金インゴット8個。結果1個。
- エンチャント版レシピ：金版を中央に、金ブロック8個。結果1個。
- 卵は16個、コーラスは64個までスタック。4アイテムともネイティブの食事処理を使わず、使用処理で動作する。
- 卵は投擲成功時、コーラスは転移成功時に1個消費。クリエイティブでは非消費。
- 満腹度と隠し満腹度は安定版Server API 2.0の `saturation` 効果を1tickだけ使用。金版はamplifier 1、エンチャント版は5。実際の補給量はエンジンの処理と満腹度・隠し満腹度の上限に従う。実機での実測は未実施。

## 実装方式

新しい `pinene:golden_extension_use` カスタムアイテムコンポーネントを登録。
既存の `pinene:golden_food_consume`、食料の能力データ、既存効果の重複規則は変更しない。
新系列だけが既存の `chooseEffect` を参照し、強い既存効果を弱めず、同レベルの残り時間を加算しない。

卵は `Dimension.spawnEntity` と `EntityProjectileComponent.shoot` により、専用Projectileを生成する。

- `pinene:golden_egg_projectile`
- `pinene:enchanted_golden_egg_projectile`

衝突ダメージ0、速度による追加ダメージ0、ノックバックなし。ニワトリ生成や孵化抽選は定義していない。
Player以外には効果を付けない。チーム判定を設けていないため、敵プレイヤーにも付与する。
1つの投射体の命中を1回だけ処理し、ブロック・Entityへの命中で消去。20秒の寿命も設けている。

## Projectile追尾方式

- 初速度：1.5ブロック/tick。
- 発射時に32ブロック以内、照準から20度以内の生存Playerを検索。
- 投擲者とスペクテイターを初期候補から除外。壁越しの候補も除外。
- 視線ベクトルとの内積が最大のPlayerを選ぶ。単純な距離順ではない。
- 頭〜胸に相当する足元+1.3ブロックを追尾。
- 球面補間により、速度の大きさを維持して1tick最大6度まで旋回。
- 対象の死亡、消失、Dimension移動、32ブロック外で再検索。有効候補がなければ現在方向へ直進。
- 通常卵は重力0.03、空気抵抗0.99。エンチャント卵は重力0、空気抵抗1。
- ネイティブのブロック衝突に加え、移動区間のRaycastを実施。壁を越えた命中ではバフを付けない。

## Teleport安全判定

- 視線方向に最大距離まで探索し、到達可能な最遠の安全な足場を選ぶ。
- 足元・胴体・頭と横幅を確認し、身長約1.8、幅約0.6ブロックの空間を要求。
- 空気以外の身体接触を拒否。低い天井、固体、液体、未読込ブロックを通過しない。
- 経路の格子境界を全て調べ、長距離や斜め方向でも薄い壁を飛ばして判定しない。
- 足場は石・土・エンドストーン・板材など、形状が分かっている通常の立方体ブロックに限定。奈落、溶岩、マグマ、サボテン、形状不明の追加ブロック等は拒否。
- 半ブロック、階段、葉、水、未知の追加ブロック上などは保守的に失敗する場合がある。空中だけに着地するワープは行わない。
- 座標指定は候補周辺±2ブロックを探索し、指定点から3ブロック以内かつ距離上限内の安全地点を選ぶ。経路の壁判定も適用。
- 最終転移は `tryTeleport` の `checkForBlocks: true`、`keepVelocity: false` を使用。
- 消費前に成功を確認。画面操作中の持ち替えやDimension移動を検出した場合も消費しない。
- 失敗時は消費しない。通常使用ではUIやチャットを表示しない。操作UIからの失敗は画面内で説明する。

## UI構成と距離

エンチャント版をスニーク使用した場合だけ、以下を表示。

1. 視線方向へワープ
2. 照準地点へワープ
3. 座標を指定：X/Y/Z。絶対座標と `~`、`~100`、`~-50` に対応
4. ヴォイドアンカー確認：残り時間と記録地点

現在地とDimension、エンドでは `End Resonance : ACTIVE` を表示。
相対座標の基準は入力フォームを開いた時の位置。
座標指定はオーバーワールド／ネザー256、エンド1024ブロック。
別Dimensionへの移動、Waystone一覧、座標保存、お気に入り、無制限移動は追加していない。

## ヴォイド・アンカー

エンドでエンチャント版ワープが成功した際、転移前の位置に安全な足場がある場合だけ60秒保存。
毎tick、エンドの建築下限より8ブロック下で下降している生存Playerを判定し、記録地点が今も安全なら1回帰還。
発動、時間切れ、死亡、退出、Dimension移動で解除。再起動をまたぐ永続保存はしない。
死亡後に復活させる機能ではなく、奈落ダメージ前の高さ判定による代替実装。瞬間的な致死ダメージへの無敵保証はない。

## 図鑑と科学説明

図鑑は既存19項目に4項目を追加し、計23項目。通常のリンゴシチューは非掲載のまま。
卵は「アミノ酸パルス」、コーラスは「ベクトル・ブリンク」。使用時には科学説明を表示しない。
卵の科学説明は実在する栄養・代謝を題材にするが、投擲による即時強化は創作と明記。
コーラスは架空植物として扱い、座標・単位ベクトル・Raycast・相対座標を説明。

## テクスチャ

バニラ16×16の卵とコーラスを元に、現在の柔らかい金リンゴ由来パレットを適用。
元画像の透明度・寸法・シルエットを維持し、陰影の階調を保持するため参照パレット間を補間。
装飾・粒子・宝石は追加していない。エンチャント版は同一PNGを参照し、アイテムの `minecraft:glint` で光る。
投擲中のスプライトは両卵とも同じ金の卵画像を使用。
