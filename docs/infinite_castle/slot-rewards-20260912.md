# BSLによる各スロット抽選 — 2026-09-12

無限城の宝箱を、一括投入から27枠の個別抽選へ変更。報酬アイテム・個数・重みはBSL BP 1.0.17で管理し、Infinite Castle BP 0.2.2は指定枠への投入と重複防止を担当する。7種類とはguard / wraith / curse / mixed / heavy / elite / treasure_vaultの報酬区分であり、アイテム数ではない。

## 抽選

- 27枠からランダムな1枠を選び、基本報酬を1回抽選して最低1スタックを保証。
- 残り26枠はBSLの空欄を含むテーブルをそれぞれ1回抽選。同じアイテムが複数枠に出る場合も、隣へまとめない。
- アイテムの個数・特殊データ・エンチャント等はネイティブのloot処理に任せる。
- 通常のBSL構造物36プロフィールは変更しない。配布済みチェストは再抽選・再配置・再補充しない。新しく報酬を生成するチェストから適用。

BSLの `loot_tables/chests/infinite_castle/slots/` に保証用・空欄込み各7テーブルを追加。元の7テーブルと既存food/collectibleを基準に `python tools/build_castle_slot_loot.py` で生成する。BSLの基準報酬を調整した場合もこのコマンドで更新する。

各枠のカテゴリ抽選は総重み2600。基本報酬の期待抽選回数をMとすると基本枠の重みは `(M-1)*100`、各追加poolの重みは `平均roll数*発生確率*100`、残りを空欄にする。保証枠と合わせて元の各poolの期待抽選回数・アイテム数量の期待値を維持する。独立枠抽選になるため、最低数量や「1回以上出る確率」、複数回当たる確率は従来と異なる。全枠へ従来の宝箱全体テーブルを27回適用する方式ではない。

平均使用枠数: guard/wraith/curse/heavy 3.17、mixed 3.67、elite 5.96、treasure_vault 10.45。

## 保存と再開

Version 3のreceiptに保証枠・次の抽選・処理中の枠を保存。成功した空欄も確定し、途中失敗からの再開時に過去の枠を再抽選しない。書き込み後の例外ではその枠を配布済みとして進める。プロセス停止を跨いだ処理中の空欄は、空当たりか未実行かを判別できないので再抽選せず確定する。この狭い停止タイミングでは任意枠1回分が欠け得るが、報酬を増殖させない。空欄を引かない保証枠のみ、未投入なら再試行する。

配布完了前の宝箱は既存の操作保護を維持。Version 2の配布済みチェストは空でも取得済みとして保持し、Version 1以前の誤った空配布だけ修復する。
