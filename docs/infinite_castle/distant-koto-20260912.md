# 飾りは遠く、本体は近くに聞こえる琴 — 2026-09-12

無限城BP 0.2.4 / RP 0.1.7。飾り更新には遠くで響く専用音、城本体の入れ替えには元の明瞭な音を使う。最新・開発用ワールドとXserverへ反映済み。ローカルは保存して入り直すと適用される。

## 聞こえ方

- 飾り更新: `infinite_castle.koto_distant`。元のA/B録音から高音を抑え、140・290・470msの弱い反射音を加えたモノラル音源を生成。再生時に各プレイヤーからX+6/Y+2/Z+4（約7.5ブロック）離れた位置を指定し、音量0.85・ピッチ1で再生する。実際の背景建築の座標ではなく、どの階でも聞こえる距離に置く演出用の音源位置。
- 城本体の入れ替え: `infinite_castle.koto`。元のステレオA/B録音をそのまま、位置指定なし・音量1・ピッチ1で近くに再生。入退場の琴も従来の録音を使う。

位置を省略するとプレイヤー近くで再生される仕様に基づく。[公式PlayerSoundOptions](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/playersoundoptions#location)。

どちらも変更が実際に始まる時に1回だけ鳴る。タイマー間隔・昼夜から独立した時計・プレイヤー保護・延期処理は継続する。録音の音程は変えていない。

## 作成・検証

`python tools/build_castle_distant_koto.py` で元のOGGから遠距離版2本を再生成できる（FFmpeg/libvorbisが必要）。元の音源ファイルがGit HEADと同一であることを確認した。

- 遠距離音源: Vorbis、44.1kHz、モノラル。A約1.32秒、B約1.27秒。元の録音より0.47秒長い残響を確認。
- デコード後ピークはA約0.652、B約0.619でクリッピングなし。両音源の非無音・残響末尾の非無音・sound定義の参照先を確認。
- 関連内部テスト8件成功。再生開始時の各プレイヤーの位置、複数階の聞き手、二重再生防止、切断した聞き手の分離、昼固定下の背景150秒/本体15分周期、再開・保護延期を確認。
- クライアントでの試聴・実機操作テストは追加していない。音の距離感・スピーカーや端末ごとの聞こえ方は未確認。
