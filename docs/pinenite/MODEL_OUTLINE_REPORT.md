# ピネナイト：モデル輪郭への変更

調査基準は main `cd53e576`。ユーザーの追加指示により、敵と自分の表示を当たり判定の箱枠から、3Dモデルの輪郭へ変更する。必要なMob・プレイヤーの描画定義への対応と、ローカル・main・XServerへの反映は承認済み。

## 実装

- 新規RP `resource_packs/pinenite_outline` を最優先で登録。既存RP内のモデル・PNG・描画定義・Zombie Gearファイルは変更していない。元のモデルとアニメーションを参照するクライアント定義を複製し、輪郭の描画だけ追加した。
- 通常Mob・プレイヤー257 IDとピネナイト装備4部位に対応。正確な対象・参照元・対象外理由は [outline_coverage.json](outline_coverage.json)。バニラは公式 `Mojang/bedrock-samples` の `v1.26.40.05`。複数世代があるIDは同一パック内の最大 `min_engine_version` を選択する。
- 元モデルの各キューブを0.06モデルピクセルだけ膨張させ、裏面側を描くマテリアルで輪郭を作る。既存の骨・ピボット・UV・アニメーション・小型個体のモデル選択・部位の表示条件を保持。色は `#39c5bb`、追加描画は照明の影響を受けない設定。壁越し表示用の深度無効化やステンシル処理は使用しない。
- 自分は身体と装備全体の輪郭。元の装備4モデル、テクスチャ8枚、ID、Parcanite由来の性能は保持。通常幅／細腕のプレイヤー用形状を用意し、バニラの短腕オフセット変数で選択する。Persona等の任意形状を動的複製する機能ではない。
- 敵の適応段階に応じた濃さ・点滅、完全共生の30tick周期の脈動、自分の10tickフェード、反射時の4tick強調をモデル表示へ移した。反射の短い粒子と跳躍の足元粒子は残す。AABBの辺を描く処理は戦闘アダプターから除去。
- 同じ敵に対する表示要求はtickごとに最大強度へ集約し、複数人の要求が上書きし合うことを防ぐ。能力の学習・適応・共生状態は従来どおり装着者と対象IDごとに独立、種類数上限なし、共生は300tick（15秒）更新。解除時は強度0を送信し、通信停止時もクライアント側の0.3秒の表示期限で消える設計。
- 元ダメージの保存・再生・適応軽減・反射再帰防止・跳躍・HP・防御値の計算は変更なし。
