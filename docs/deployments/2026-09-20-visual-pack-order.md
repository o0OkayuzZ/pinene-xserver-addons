# 開発ワールドと影パックの優先順位を統一

古いWindows受信キャッシュを退避しても、Xserverだけ影の見た目が古いという報告が継続した。影パック1.3.32の素材は一致していたが、開発ワールドではRP一覧の先頭、Xserverでは11番目に登録されていた。従来の比較はUUIDごとの内容・登録情報だけを比較しており、配列の順序差を検出できていなかった。

Xserverのルートと`worlds/Bedrock level`の`world_resource_packs.json`で、影RPを先頭へ移動。他の登録エントリーの内容と相対順序は維持した。変更後、開発ワールドとサーバーワールドのRP登録20件が順序・版・subpackを含め完全一致することを確認。

影RPは独立管理のため、この統合リポジトリのworld_resource_packs.jsonへ新たに登録はしない。今回の変更対象はXserverの実行時登録だけ。

バックアップ: `/opt/minecraft/server/_pinene_deploy_backups/visual-order-20260920-212838`。接続者0人を確認して再起動した。初回はTCP受付が開始せず、19132のTIME-WAITを観測。時間を置いた再起動後に外部HTTP接続受付が復帰した。ゲーム内の描画改善はユーザー確認待ち。優先順位差は確認済みだが、今回の表示症状の唯一の原因とまでは確定していない。
