# Alylica's Dungeons 2.1.3 integration

The 2.1.3 update was prepared as `74de23ed` and published on server main as `3e23e60e`, retaining the Infinite Castle return/chest synchronization fix from `78c5e1b0`. This follow-up applies the validated compatibility fixes on top of that published update. Source: the author's `Dungeons2.1.3.mcaddon` supplied locally.

Both Dungeons pack UUIDs are unchanged. BP uses the author's manifest format 3 and string version `2.1.3`; RP and world registrations use `[2, 1, 3]`. The BP's RP dependency is corrected from `2.1.0` to `2.1.3`. Existing dependent resource packs, both world registration copies, README and website pack registry match the release.

The original integration retained Japanese localization, project equipment and customized boss rewards. This follow-up restores nine legacy smithing/UI textures that the update removed but the Deathnerite metadata pack still references. Metadata auditing now compares format 3 string versions with equivalent format 2/world array versions, with a regression test that also rejects stale dependencies.

Validation:

- All 3,587 incoming BP files and 7,557 incoming RP files are represented in the integrated packs; the author archive has no missing files in the result.
- All JSON/JSONC files in both integrated packs parse.
- All 419 Dungeons JavaScript files pass `node --check`.
- `python tools/test_dungeons_boss_rewards.py`: 4 tests pass.
- `python -m unittest discover -s tools/tests -p test_pack_metadata.py -v`: 5 tests pass.
- `python tools/audit_pack_ownership.py`: passes, including Deathnerite texture ownership.
- Crossbow tests: 12/15 pass. The three failures concern an existing legacy texture duplicate and pre-existing sniper charge/FOV expectations. The tests and their BP09/RP05/RP07 inputs are unchanged from `78c5e1b0`.
- The broader Pinenite suite still contains old baseline-preservation checks and references to a removed blue-apple recipe/previous texture ownership. Those historical checks are not treated as validation of a Dungeons release upgrade. Its Dungeons crossbow model/material/texture alias check passes.

Local target is the existing world named `開発用ワールド` (`8v9pvwiD6QQ=`). Before installation its Dungeons files matched pre-update main semantically (JSON formatting/line endings ignored), with no local-only additions or deletions. Installation backs up every replaced/deleted file and records additions before applying the diff; it preserves other world content and only adjusts Dungeons dependency/registration versions in other files. Both installed packs are verified against the integrated source using SHA-256.

In-game startup, rendering, new content and server runtime behavior have not been tested. Updating GitHub main is separate from deploying to a running server.
