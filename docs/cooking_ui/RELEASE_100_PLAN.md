## 制作範囲

素材を除いて料理100品。無料10品＋追加パック90品。既存27品、名前を採用済みの27品、新規46品を含む。食材7レシピ、ホールチーズ、唐辛子、まな板13種、ナイフ5種は品数に含めない。

100品の名前・材料・Rank・食料回復・腹持ち・効果・区分は `catalog-100.json` が所有する。実機で調整する数値の初稿であり、採用済みの新規画像・3Dモデル・実機確認が揃ったことを意味しない。

## 無料10品

はちみつパン、チョコパン、キャロットサラダ、海藻サラダ、エッグトースト、チキンサンド、パンプキンスープ、じゃがバター、フライドポテト、パンケーキ。基本素材・道具は共通。無料料理は追加パックの料理を要求しない。

## 効果の設計

食料回復と腹持ちを土台に、探索・暗所・海中・採掘・防御・戦闘・回復などを使い分ける。追加効果のない日常食も設ける。効果はすべてI、最大2種類。再生は3～6秒、攻撃力上昇は20～30秒、耐性は20～35秒。火炎耐性と落下速度低下はRank VIIと希少素材を要求する。既存の強い・長い効果を弱めない。

全料理で食事効果の再発動待ちは30秒を共有する。食料回復は通常どおり。食べ始め・中断では効果を出さず、実際に食べた時だけ発動する。満腹時には食べられない。待ち時間はプレイヤーごとに保存する。現実の食品の健康効果を表現するものではない。

## 実装済みの候補

- 100品のitem・調理データ・食事効果と料理図鑑の数値説明。
