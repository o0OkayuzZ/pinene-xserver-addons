# 通常クリーパーの最新バニラ画像への復帰

PR #42は描画参照の競合を修正したが、アドオンの古い通常クリーパー画像を維持していた。ユーザーから「最新バニラの見た目、エフェクトはそのまま」と追加指定されたため、通常時の画像だけを公式の最新安定版に合わせる。

## 変更

- Mojang/bedrock-samples の最新安定リリース `v1.26.50.4` から、`creeper.png`・`creeper.texture_set.json`・`creeper_mers.tga` を加工せず取得。
- 優先度の高い輪郭RPに同じパスで配置し、下位Dungeons RPの古い画像を上書き。Vibrant Visualsの質感も公式マップと一致させる。
- 取得元とファイルハッシュを `docs/pinenite/creeper_vanilla_assets.json` に記録。既存のMojangライセンス表示を維持。
- 輪郭RPを1.0.9にし、依存・ワールド登録・生成器の版を同期。

通常クリーパーのクライアント定義、モデル、帯電画像、グリント、粒子効果と強化・氷クリーパーの専用表示は変更しない。湧きルール・変身率も変更しない。

## 検証

公式画像とのSHA-256一致、旧アドオン画像との差、質感マップの解決と同寸法、帯電・輪郭パスの別名解決、元のエフェクト定義の維持を3件で検証。既存の互換性・輪郭参照など5件も通過。

配布元: https://github.com/Mojang/bedrock-samples/tree/v1.26.50.4/resource_pack/textures/entity/creeper
